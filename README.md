📄 Analisador de Currículos com IA (Google ADK)Este projeto é um agente inteligente construído com o Google Agent Development Kit (ADK). Ele atua como um assistente de Recrutamento e Seleção: lê currículos (em PDF ou texto), extrai informações essenciais, avalia o "match" do candidato com a vaga desejada e salva os dados estruturados automaticamente em uma base de dados no formato Excel (.xlsx).🛠️ Tecnologias UtilizadasPython 3.10+Google ADK (Agent Development Kit)Google Gemini 2.5 FlashPydantic (Validação de dados)Openpyxl (Manipulação de planilhas Excel)🚀 Como Instalar e Configurar1. Criar e ativar o ambiente virtualAbra o seu terminal na pasta raiz do projeto e crie um ambiente virtual (.venv) para isolar as dependências:python -m venv .venv
Em seguida, ative o ambiente virtual:No Windows:.venv\Scripts\activate
No Linux/Mac:source .venv/bin/activate
2. Instalar as dependênciasCom o ambiente ativado, instale as bibliotecas necessárias usando o arquivo de requisitos:pip install -r requirements.txt
(Nota: Certifique-se de que o seu ficheiro requirements.txt contenha google-adk, pydantic e openpyxl).3. Configurar a Chave de APICrie um ficheiro chamado .env na raiz do projeto e adicione a sua chave do Google AI Studio:GOOGLE_API_KEY="SUA_CHAVE_API_AQUI"
GEMINI_API_KEY="SUA_CHAVE_API_AQUI"
💻 Como Usar o AgenteIniciando a Interface WebNo terminal (sempre com o .venv ativado), certifique-se de que está na pasta raiz e execute o comando abaixo para subir o servidor do ADK:adk web --port 8000
Aceda à interface no seu navegador através da ligação: http://localhost:8000O Fluxo de Trabalho (Passo a Passo)Para garantir que a IA avalia corretamente a Aderência ("Match") do candidato em relação ao que a empresa precisa, siga esta ordem no chat:Selecione o agente: No canto superior esquerdo da interface web, escolha o agente correspondente (ex: analisador_curriculos).Defina a Vaga (Contexto): Envie uma primeira mensagem de texto a explicar qual é a vaga em aberto e os requisitos.Exemplo: "A partir de agora, vou enviar currículos para a vaga de Desenvolvedor Python Pleno. O candidato ideal precisa de ter experiência com APIs, banco de dados e inglês avançado."Envie o Currículo: Faça o upload do ficheiro PDF do candidato clicando no ícone de clipe ou cole o texto do currículo no chat.Análise e Registo: O agente vai ler o documento, extrair os campos, calcular a aderência com base na vaga que definiu no passo 2 e registar tudo na sua folha de cálculo base_agente.xlsx.⚠️ Avisos e Resolução de Problemas (Troubleshooting)Erro de Permissão (PermissionError - Errno 13): O Python necessita de permissão de escrita para adicionar as linhas na folha de cálculo. Mantenha o ficheiro base_agente.xlsx sempre fechado no Excel ou em outro programa enquanto o agente estiver em execução. Se estiver aberto, ocorrerá uma falha ao tentar gravar os novos candidatos.Limites do Plano Gratuito (429 RESOURCE_EXHAUSTED): O modelo do Gemini possui um limite de requisições por minuto (RPM) no plano gratuito. Como a interface gráfica faz várias chamadas para gerir a sessão, este limite pode ser atingido rapidamente. Se isso acontecer, aguarde entre 30 a 60 segundos e tente novamente.
